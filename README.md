# crono

This repository contains a Unity project. The C# scripts are organized under `Assets/Script`.

The game now includes a multi-level **Bridge** building that lets characters traverse water tiles.

## Folder Structure

- `Actions/` - gameplay actions and related interfaces
- `AI/` - artificial intelligence scripts
- `Characters/` - character classes and roles
- `Managers/` - various manager components
- `Players/` - player-related classes
- `UI/` - user interface helpers and components
- `World/` - world generation and environment utilities
